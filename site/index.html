Features

Session tiles

Nine per page, filled with each agent's color. Model, branch and a context bar at a glance.

Never miss a finish

Finished or unread sessions blink until you press them. Pressing opens that session.

Limits in view

The 458x196 panel shows one row per agent with 5-hour and weekly limit bars.

One file per agent

Each agent is an independent module. Adding one never touches the dashboard code.

Deck controls

ButtonAction
Session tiles (0–8)Mark as seen and open that session
Next (9)Next session page; from the last page back to page 1
Bottom tiles (10–12)Per-agent limits (5H and weekly). Press any to switch remaining / used % and refresh

Install

Clone the repository, then:

python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python.exe dashboard.py

Or run deploy.bat. To run without a window use run_silent.vbs; to start at every login run install_startup.bat as administrator.

Add an agent

  1. Create agents/<name>.py with KEY, LABEL, SHORT, COLOR, BG, APP_TITLE.
  2. Implement sessions() and usage(); add focus(session) if a deep link is not enough.
  3. Add it to MODULES in agents/__init__.py.
