agentmon

Session status and usage limits of your coding agents (Claude Code, Codex, Antigravity) on an Ulanzi D200 deck.

  • Session tiles with model, branch and context bar; finished sessions blink until pressed
  • Wide 458x196 panel with 5-hour and weekly limit bars per agent
  • Agents are independent modules: add one file, no dashboard changes
  • Windows, Python 3, Ulanzi D200
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python.exe dashboard.py
